# Upload to the existing AI Systems Architecture repository

1. Download the prepared ZIP and extract it on your Mac.
2. Open the **existing** `observatory-ai-systems-architecture` repository on GitHub.
3. Choose **Add file → Upload files**.
4. Drag the **`runtime-evidence` folder** into the uploader (not the original `node.zip` or `active.zip`).
5. Confirm uploaded paths begin with `runtime-evidence/` before committing.

Your repository should then contain sibling folders `engine-archive/`, `framework/`, `architecture/`, and `runtime-evidence/`.

Do not upload original operational databases or logs: the aggregate snapshot is already included. Once committed, we can prepare the **repository-root README** and connect these four folders into a coherent navigable portfolio.
